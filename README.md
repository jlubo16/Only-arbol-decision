Árbol de Decisiones - Plyvara Versión beta

Este repositorio contiene únicamente los archivos relacionados con la implementación del árbol de decisiones desarrollado para Plyvara, una tienda de productos de papercraft.

Descripción

El árbol de decisiones fue implementado en Angular como una mejora de la experiencia de usuario dentro de la tienda. Su objetivo es guiar al usuario mediante preguntas paso a paso para recomendar productos personalizados según sus preferencias.

El sistema funciona a través de preguntas y respuestas donde cada elección conduce a una nueva opción hasta llegar a una recomendación final.

Funcionalidades
Flujo dinámico de preguntas y respuestas.
Navegación entre nodos del árbol.
Recomendación personalizada de productos.
Estructura modular implementada en Angular.
Tecnologías utilizadas
Angular
TypeScript
HTML
CSS
Nota

Este repositorio incluye únicamente la lógica y componentes relacionados con el árbol de decisiones.
